# MaazXevents

Event management platform built with React, Vite, and Tailwind CSS. Features a custom CMS with image uploads via Vercel Blob and Gemini AI integrations.

## Features

- Event listings and management with a custom CMS
- Image uploads powered by Vercel Blob
- Gemini AI-powered assistance
- Responsive, modern UI with Tailwind CSS

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Build

`npm run build`
